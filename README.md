# Support Ticket Analyzer

A small data-analysis tool for operations work: feed it a CSV export of
support tickets and it produces a plain-language summary — ticket volume
by category and priority, average resolution time, and SLA breach rates
per priority. The kind of weekly report an Operations Executive actually
prepares for a team review.

## How to run

```bash
pip install -r requirements.txt
python analyzer.py tickets.csv --report report.md --summary summary.csv
```

Swap `tickets.csv` for your own export — it just needs the columns
`id, created_date, resolved_date, category, priority, status`
(dates as `YYYY-MM-DD`; `resolved_date` blank for open tickets).

## SLA targets

| Priority | Target resolution time |
|---|---|
| Critical | 8 hours |
| High | 24 hours |
| Medium | 72 hours |
| Low | 120 hours |

| Priority | Resolved | Avg resolution (h) | Breaches | Breach rate |

The headline finding in the sample data: High-priority tickets breach
their 24-hour SLA most often (37.5%) — the place to focus first.
